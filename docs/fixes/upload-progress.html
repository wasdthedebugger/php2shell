Turn off session upload progress

CVE-2026-109619

This is a temporary setting. It reduces the risk but does not fix the bug. Update PHP to fix it for real.

What

session.upload_progress.enabled = 0

Why

This feature is one confirmed way to reach CVE-2026-109619. It must be set in config that loads before the request is read: php.ini, the PHP-FPM pool or the server config. Not ini_set() and not .user.ini, which load too late.

Watch out

Upload progress bars that read from $_SESSION stop working. Most sites don't use them.

Set it by hand

Your setupWhereAdd this
Any (php.ini)php.ini, or a new file in its conf.d foldersession.upload_progress.enabled = 0
PHP-FPMpool file, e.g. /etc/php/8.3/fpm/pool.d/www.confphp_admin_flag[session.upload_progress.enabled] = off
Apache mod_phpserver or VirtualHost configphp_admin_flag session.upload_progress.enabled off
Docker (official image)your DockerfileRUN echo "session.upload_progress.enabled = 0" >> /usr/local/etc/php/conf.d/99-php2shell.ini
Windows / XAMPP / IISphp.ini in your PHP foldersession.upload_progress.enabled = 0
Shared hostingAsk your provider. .user.ini and .htaccess are not reliable for this (why).

Then restart PHP. Nothing changes until you do.

Undo

Run php php2shell.php --undo and pick the change. Or remove the line by hand and restart PHP.
