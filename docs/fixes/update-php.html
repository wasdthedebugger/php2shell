How

  • Ubuntu / Debian: sudo apt update && sudo apt upgrade. Your version number may not change: the vendor patches it in place. Check Ubuntu or Debian.
  • Red Hat / Rocky / Alma / Fedora: sudo dnf upgrade. Check Red Hat.
  • macOS (Homebrew): brew upgrade php
  • Windows: download the new version from php.net, or update XAMPP/Laragon.
  • Docker: bump the tag in your Dockerfile (e.g. php:8.3.36-fpm) and rebuild.
  • Shared hosting: pick the newest PHP in your panel and ask your provider to confirm.

Then restart PHP. After that, undo the temporary settings: php php2shell.php --undo. In particular, you want memory_limit back to a normal value.
